# Analysis of Machine Learning-based Human Activity Prediction Model for Assistive Exoskeleton

This repository contains the implementation and experiments for the paper:

**"Analysis of Machine Learning-based Human Activity Prediction Model for Assistive Exoskeleton"**  
📌 Presented at **ACDSA**  
📌 Published in **IEEE Xplore**

---

## 📖 Overview
This project explores machine learning techniques for predicting human activities to improve the control and adaptability of assistive exoskeletons.  
The repository includes:
- Data preprocessing and feature extraction pipelines  
- Implementation of multiple machine learning models  
- Comparative analysis of model performance  
- Scripts for training, evaluation, and visualization  



## 🚀 Future Improvements

The following directions are identified for future work:

- **Real-time prediction on embedded hardware** — Deploy the trained models on low-power embedded platforms (e.g., microcontrollers or edge AI chips) to enable on-device, real-time activity recognition for the exoskeleton control loop.
- **More test subjects for the dataset** — Expand the data collection to a larger and more diverse pool of participants to improve model generalization and robustness across different body types and movement patterns.
- **Comparison with transformer-based models** — Evaluate attention-based architectures (e.g., Vision Transformers, Temporal Transformers) against the CNN/RNN baselines to assess whether self-attention mechanisms yield accuracy or latency improvements for this task.
